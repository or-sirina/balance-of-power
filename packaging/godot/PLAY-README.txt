BALANCE OF POWER — GODOT PROTOTYPE

English
Extract the complete archive, keeping its files together. Run BalanceOfPower
(on Windows, BalanceOfPower.exe) from the extracted folder. No separate Python
or Godot installation is needed. For Russian, run with --language ru; for
English, use --language en. Settings and saves are stored in your user profile.
Keep the credits folder when sharing the game. The Help menu contains a full
English/Russian manual. Multiplayer includes LAN, hotseat and shared-folder
play-by-mail; Godot cannot directly crossplay with older Qt clients.

Русский
Распакуйте архив целиком, сохранив все файлы вместе. Запустите BalanceOfPower
(в Windows — BalanceOfPower.exe) из распакованной папки. Отдельно устанавливать
Python или Godot не нужно. Для русского языка используйте параметр --language ru,
для английского — --language en. Настройки и сохранения хранятся в профиле
пользователя. При распространении игры сохраняйте папку credits. В меню Help
доступно полное руководство на русском и английском языках. Есть игра по
локальной сети, за одним компьютером и через общую папку; прямая совместная
игра Godot со старыми клиентами Qt не поддерживается.

This prototype is under development. Builds are platform-specific. The macOS
CI package targets Intel x86_64; signing and notarization are not yet configured.
Linux requires compatible system libraries.
