# Native packaging builds

Build on Linux, Windows, and macOS hosts separately. Install Godot 4.7.2 and its matching export templates plus PyInstaller in each host's Python environment, then run `python tools/build_godot.py --platform linux|windows|macos` with the value matching the host. The build writes a platform archive under `dist-godot/`; publish it only after smoke testing the frozen launcher and exported client on that host. PyInstaller is not a cross-compiler.

Linux produces an exported Godot client and a frozen Python launcher with its runtime and data. PyInstaller does not bundle system libraries such as glibc; the build host determines compatibility, so validate on target Linux distributions. CI uses Ubuntu 24.04, Windows Server 2022 and macOS 15 Intel hosts. The macOS build extracts the Godot app alongside the frozen launcher, which discovers its executable through Info.plist. This is not yet an integrated, signed or notarized macOS application. Code signing, notarization, platform security prompts, interactive clean-machine testing, and release distribution remain work beyond automated headless validation. Preserve the `credits` directory and Godot license with distributions.

References: [Godot exporting projects](https://docs.godotengine.org/en/stable/tutorials/export/exporting_projects.html); [PyInstaller operating modes](https://pyinstaller.org/en/stable/operating-mode.html).

The macOS CI job uses the explicit `macos-15-intel` runner. GitHub retired macOS 14 runners on November 2, 2026; see the [runner image support list](https://github.com/actions/runner-images#available-images). Python 3.12.10 and PyQt5 5.15.11 provide Intel builds, and the pinned Godot editor is universal. The frozen Python launcher is Intel x86_64, so the complete macOS archive is not a universal native build; native Apple Silicon validation requires a separate arm64 build.

The `credits` folder preserves Godot engine and third-party notices, Python and PyInstaller licenses, and music and portrait attribution. The Linux archive preserves executable permissions; extract it before running `linux/BalanceOfPower`.

The workflow in `.github/workflows/godot-desktop.yml` runs for pull requests targeting `main` and supports manual dispatch after the workflow is present on the default branch. To validate a future published branch without merging it, open an approved draft pull request targeting `main` and review its workflow checks. It installs checksum-pinned official Godot 4.7.2 editors and templates, runs source and frozen smoke tests on native Linux, Windows and macOS runners, and uploads archives only after those checks pass. See [PR #1 checks](https://github.com/or-sirina/balance-of-power/pull/1/checks) for current native results and follow a successful workflow run to download its artifacts. The helper `tools/install_godot_ci.py` uses the universal macOS editor, compatible with both Apple Silicon and Intel, and never reads player configuration.
