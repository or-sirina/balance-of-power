# Native packaging build proposal

Build on Linux, Windows, and macOS hosts separately. Install Godot 4.7.2 and its matching export templates plus PyInstaller in each host's Python environment, then run `python tools/build_godot.py --platform linux|windows|macos` with the value matching the host. The build writes a platform archive under `dist-godot/`; publish it only after smoke testing the frozen launcher and exported client on that host. PyInstaller is not a cross-compiler.

Linux produces an exported Godot client and a frozen Python launcher with its runtime and data. PyInstaller does not bundle system libraries such as glibc; the build host determines compatibility, so validate on target Linux distributions. Windows and macOS presets and builds have not been validated. The macOS build extracts the Godot app alongside the frozen launcher, which discovers its executable through Info.plist. This is not yet an integrated, signed or notarized macOS application. Code signing, notarization, platform security prompts, clean-machine testing, and release distribution remain work for native runners. Preserve the `credits` directory and Godot license with distributions.

References: [Godot exporting projects](https://docs.godotengine.org/en/stable/tutorials/export/exporting_projects.html); [PyInstaller operating modes](https://pyinstaller.org/en/stable/operating-mode.html).

The `credits` folder preserves Godot engine and third-party notices, Python and PyInstaller licenses, and music and portrait attribution. The Linux archive preserves executable permissions; extract it before running `linux/BalanceOfPower`.

The workflow in `.github/workflows/godot-desktop.yml` runs for pull requests targeting `main` and supports manual dispatch after the workflow is present on the default branch. To validate a future published branch without merging it, open an approved draft pull request targeting `main` and review its workflow checks. It installs checksum-pinned official Godot 4.7.2 editors and templates, runs source and frozen smoke tests on native Linux, Windows and macOS runners, and uploads archives only after those checks pass. It has not been dispatched; native Windows and macOS results are not yet available. The helper `tools/install_godot_ci.py` uses the universal macOS editor, compatible with both Apple Silicon and Intel, and never reads player configuration.
